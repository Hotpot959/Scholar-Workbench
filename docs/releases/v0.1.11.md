# Scholar Workbench 0.1.11 — Protocol 附件与本地浏览

## 本次更新

### 实验 Protocol 附件

- 每个实验方法新增“Protocol 文件”区域，可上传多张图片或多个文件，与原有实验用品和 Step 流程一起管理。
- 图片、PDF、文本可在应用内浏览；DOCX、XLSX 提供内容预览。复杂排版、文档中的图片和公式请通过“用系统应用打开”查看原文件。
- 支持将附件另存为本地文件；暂不支持内嵌预览的格式仍可完整保存。

### 保存、回收站与完整同步

- Protocol 附件保存在本机，无需上传到服务器。
- 删除的 Protocol 附件或整个实验方法可从回收站恢复；完整同步文件同时包含这些附件。
- 兼容旧版完整同步文件，保留原有方法名称、用品、步骤以及其他模块记录。
- 包含 Protocol 附件的新同步文件，请在 0.1.11 或更新版本中恢复；旧版软件不具备此附件功能。
